# FOLDORA v0.3

本机运行的桌面包装编辑器。可以使用修正后的插接式锁底盒模板，也可以从空白或模板副本绘制单张连通纸板的自定义刀板。设计面板、查看折叠、检查印前问题并导出完整刀板 RGB 校样 PDF。

## 启动

需要 Node.js 20.9 或更新版本：

```bash
npm ci
npm run dev
```

在桌面浏览器打开 <http://localhost:4187/editor>。项目、素材和备份前的源记录保存在当前浏览器的 IndexedDB；正式作品建议从“项目”菜单定期下载 `.foldora` 备份。

## 模板盒型

左侧输入 W、D、H、Glue，点击“更新刀板”后统一应用。W/D 为 40–200 mm，H 为 80–400 mm，Glue 为 5–30 mm 且不能超过较小侧宽的三分之一。尺寸更新可撤销；现有图案保留原来的毫米坐标，越界时由印前检查提示。

模板修订 2 把最右锁底折片外缘改为竖线，调整背锁片缺口与侧折片伸入深度，并把背侧顶片按现有压痕分段折到顶盖内侧。90 × 90 × 235 mm 及三组非正方形尺寸均有底部覆盖与几何回归测试。旧 v0.1 几何黄金样本仍保留在测试夹具中。

## 自绘刀板

从顶部“项目”菜单选择“新建空白刀板”或“复制为自绘刀板”，然后进入“刀板编辑”。可绘制闭合 CUT 外轮廓、开孔、开放 CUT 直线、直线 CREASE、仅在编辑器显示的辅助线、矩形、椭圆和贝塞尔曲线。选择轮廓后可拖动节点或曲线控制柄，并输入毫米坐标；压痕可输入端点、长度、线段角度、山折／谷折、目标折角、开始／结束进度及叠放层级。网格可选 0.1、0.5、1、5 mm，支持节点、边缘、水平和垂直吸附。

绘制外轮廓及直线压痕后点击“识别并确认面板”，确认名称、可印刷状态和 3D 基准面。任意已确认的可印刷面板都能独立添加文字和图片；图案按面板轮廓与开孔裁切。改形状时对象保留原毫米位置。合并或拆分导致已有图案失去面板归属时，界面会先要求选择新面板，一次应用并可撤销。

未闭合轮廓、越界开孔、自交、跨面开孔、无效压痕、未确认面板、连接闭环或合盒穿透可以作为草稿保存；印前检查列出问题，3D 与完整刀板 PDF 等待结构修复。首版支持单张连通纸板、直线铰链和无闭环折叠；SVG/DXF 导入、自由手绘、曲面折叠及跨面连续图案暂未提供。

## 设计、预览与导出

- 2D 面板支持文字、30 款本机字体、内置 SVG 和最大 10 MB 的 PNG/JPG 图片；文字属性、图层、撤销／重做和自动保存沿用 v0.2 行为。
- 3D 预览有 0–100% 折叠进度、展开／半折／合盒／播放；左键可切换旋转或平移，右键始终平移。滚轮与 25%–400% 滑杆共用缩放状态；复位恢复视角、平移与 100% 缩放，保留折叠进度。
- 顶部单个“导出”菜单提供“当前面 PNG”“当前面 JPG”“完整刀板 RGB 校样 PDF”。PNG/JPG 按原有 1200 px 规则输出；PDF 按毫米确定页面，面板位图默认 300 DPI、草稿 150 DPI，CUT／CREASE／开孔保留矢量，出血与辅助线可配置。
- PDF 是 **RGB 校样**，不是 CMYK、ICC、PDF/X 或印厂认证生产文件。折片与合盒效果为结构示意，实物打样仍需校核纸材、厚度和工艺公差。

“项目”菜单支持新建、复制、重命名、切换、确认后删除、下载和导入单项目 `.foldora` 备份。备份包含项目数据及上传图片；导入会校验并新建项目，不覆盖已有作品。现存 v2/v3 项目首次打开会自动升级到 v4，并在同一 IndexedDB 事务中保存升级前记录；旧 `diecut-preview` 数据库保留。损坏的当前项目会报错，避免以空项目覆盖。

## 验证

```bash
npm test
npm run typecheck
npm run lint
npm run build
npm run test:e2e
```

端到端测试使用 Playwright Chromium。若本机已有 Next 开发服务，可在构建后启动独立生产预览：

```bash
npx next start -p 4190 -H 127.0.0.1
E2E_BASE_URL=http://127.0.0.1:4190 npm run test:e2e
```

## 代码与交接

- `src/core/box/reference.ts` 与 `tests/fixtures/v01-geometry.json` 保留历史基线；`geometry.ts` 生成修订后的模板，`custom.ts`、`pathEdit.ts`、`foldCheck.ts` 处理自绘结构。
- `src/core/project/` 定义 v4 项目、撤销／重做、迁移、本机多项目与 `.foldora` 备份。
- `src/core/print/` 处理印前检查和 PDF 合成；`src/components/editor/` 提供 2D、刀板编辑和 3D 视图。
- `docs/Packaging_Platform_v0.3_Handoff.md` 记录几何修订、兼容、验收结果与限制。
