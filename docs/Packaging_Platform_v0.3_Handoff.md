# FOLDORA v0.3 交接：自绘刀板与折叠修正

## 交付范围

版本 `0.3.0`，在 v0.2 五面设计、30 款本机字体、自动保存、撤销／重做、辅助线、印前检查、当前面 PNG/JPG 和完整刀板 RGB 校样 PDF 的基础上完成：

- 修正模板锁底、顶盖和最右折片的结构；保留 `v01-geometry.json` 作为历史基线，新增修正版几何样本。
- 支持空白绘制或复制模板为自绘刀板；识别面板、确认折叠关系、设计任意已确认的可印刷面，并用于 2D、3D、印前和 PDF。
- 3D 加入旋转／平移切换、右键平移及与滚轮同步的 25%–400% 缩放滑杆。
- 顶部三个导出入口合并为“导出”菜单；增加本机多项目、`.foldora` 单项目备份与导入。

## 自绘结构与操作

“项目”菜单可新建空白自绘项目或复制当前模板／自绘项目。“刀板编辑”支持闭合 CUT 外轮廓、多个开孔、开放 CUT 直线、直线 CREASE、仅编辑器显示的辅助线，以及矩形、椭圆、贝塞尔曲线。路径节点和控制柄可拖动并输入毫米坐标；网格可设 0.1／0.5／1／5 mm，吸附节点、边、水平和垂直方向。压痕可输入端点、长度、角度、山折／谷折、0–180° 目标角、动画区间和叠放层级。

核心结构在 `src/core/box/custom.ts`：由一条外轮廓、开孔、开放刀线与压痕推导面板，并要求用户确认面板名称、可印刷状态、基准面、铰链折向和顺序。首版范围为**单张连通纸板、直线铰链、无闭环连接**。面板路径与开孔同步裁切 2D、3D 和 PDF 中的图案；开放刀线在 3D 中显示为线条标记，当前不会把纸板网格切成实体缝隙。`foldCheck.ts` 检查非相邻面板在合盒时的穿透；结构不完整可以保存草稿，但会阻止 3D 和完整刀板 PDF。几何变化保留图案原毫米坐标；带图案面板被拆分或合并时先确认归属，再作为一次可撤销操作应用。

`pathEdit.ts` 在编辑节点／控制柄时保留未修改的 SVG 曲线和圆弧命令。`resolve.ts` 是模板与自绘数据的统一几何入口。自绘图案以面板稳定 ID 存储；候选面板、无效铰链、交叉、越界对象、素材和字体状态会进入印前检查。

## 数据、迁移和导出

Project v4 包含稳定 ID、名称、打印设置、素材、按面板 ID 保存的图案，以及 `mode` 和结构来源。模板保留 `templateRevision:2` 与尺寸；自绘项目保存路径、压痕、辅助线、标记和根面板，2D／3D／印前／PDF 由这些数据派生。v2/v3 首次加载时升级为修正版模板，同时在**同一 IndexedDB 事务**保存原始记录为 `original-v2`／`original-v3`；损坏记录会报错且不被空项目覆盖。旧 `diecut-preview` 数据库仍保留。

本机项目可新建、复制、重命名、切换和确认后删除。`.foldora` 备份为版本化 JSON 包，包含项目与上传图片；导入时校验结构与素材、重新分配项目和上传素材 ID，并在同一事务写入新项目及素材，不覆盖原项目。备份最大 100 MB，单张上传素材最大 10 MB；定期下载备份仍是防止浏览器清理本地数据的必要措施。

顶部“导出”菜单保留原 1200 px 当前面 PNG/JPG，并提供完整刀板 RGB 校样 PDF。PDF 的页面按毫米转 pt，面板图案按 150／300 DPI 渲染，CUT、CREASE、孔洞及开放刀线为矢量。可配置出血、CUT、CREASE；结构不完整或缺失素材、字体时显示具体阻止原因。PDF 不含编辑控件。它是 **RGB 校样**，没有 CMYK、ICC、PDF/X 认证；出血线不自动将图案延伸至折片或出血区。

## 已知边界

自绘模式没有 SVG/DXF 导入、自由手绘、曲面折叠、跨面连续图案或纸板厚度模拟。自绘开放 CUT 线在 3D 仅作结构指示；实际切开的缝需生产打样确认。合盒碰撞使用面板多边形的几何检测，不能替代纸张物理仿真。模板顶片与底锁的折叠顺序、毫米参数仍以现有参考图为依据，尚未有实物样盒校准。

30 款字体的逐项来源、许可、字重与覆盖见 [v0.2 交接](./Packaging_Platform_v0.2_Handoff.md)。本版未调整该注册表或字体文件。
